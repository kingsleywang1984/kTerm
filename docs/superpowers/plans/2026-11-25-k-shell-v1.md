# k-shell v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A lightweight macOS terminal with a sidebar of session tabs and a read-only, per-tab git diff view for reviewing what parallel Claude Code agents changed.

**Architecture:** Tauri 2 app. Rust owns PTYs (portable-pty, batched output), per-tab cwd detection, and all git access via the `git` CLI. A vanilla TypeScript frontend renders xterm.js terminals (WebGL on the visible tab only), the sidebar, a diff view (diff2html) and a git panel. "Open diff for a target" is one frontend function with two entry points.

**Tech Stack:** Tauri 2, Rust (portable-pty, libproc, serde; tempfile for tests), TypeScript + Vite, @xterm/xterm + addon-fit + addon-webgl, diff2html + highlight.js, vitest.

**Spec:** `docs/superpowers/specs/2026-11-25-k-shell-design.md`

## Global Constraints

- macOS only.
- App lives in `app/` (scaffold: `pnpm create tauri-app@latest app --template vanilla-ts --manager pnpm --identifier com.kshell.app -y`). `spike/` is reference only; do not import from it.
- Only the visible terminal holds a WebGL renderer; switching away disposes it.
- Closing a tab disposes the xterm instance, its DOM, the PTY and kills the child process.
- Scrollback cap: 10,000 lines per terminal.
- PTY output batched in Rust: flush every 8 ms or at 1 MB, whichever first.
- The diff view is created on open and fully released on close.
- Diff view and git panel are read-only. No git command that writes (no checkout, add, commit, worktree add/remove, branch -d).
- Default branch resolution order: `origin/HEAD` target → `main` → `master`.
- Tab title: manual name if set, else basename of the tab's cwd, else `Terminal <id>`.
- Shortcuts: `Cmd+T` new tab, `Cmd+W` close tab, `Cmd+1..9` switch, `Cmd+D` toggle diff for current tab, `Cmd+G` toggle git panel, `Esc` closes diff view / git panel.
- No git commits by the implementer. The user commits when they choose. Skip every "commit" step.
- Code and comments in English; no explanatory comments; no tests beyond those listed.

## Review Focus

1. Tab whose cwd is not inside a git repo: subtitle empty, `Cmd+D` shows "Not a git repository" instead of failing. → Task 3 test `repo_info_outside_repo_is_none`, Task 5 test `summary_outside_repo_errors`.
2. Repo with no `origin/HEAD`, `main` or `master` (e.g. only `develop`), or a repo with no commits: diff falls back to showing uncommitted + untracked changes against `HEAD` (or the empty tree). → Task 5 tests `base_falls_back_to_head_without_default`, `base_is_empty_tree_without_commits`.
3. Binary files and huge files (lockfiles): listed, but the patch is not rendered; show "Binary file" or "Diff too large" (patch over 1 MB). → Task 5 tests `binary_file_marked`, `huge_patch_truncated`.
4. Paths with spaces, unicode, renames and deletions appear correctly in the file list. → Task 5 test `summary_handles_special_paths`.
5. The shell exits (`exit`, or the process dies): its tab closes itself and the PTY session is removed. → Task 1 test `exit_callback_fires`.

### Task 5: Diff backend

**Files:**
- Create: `app/src-tauri/src/diff.rs`
- Modify: `app/src-tauri/src/lib.rs`

**Interfaces:**
- Consumes: `git::git`, `git::testutil`.
- Produces:
  - `#[serde(tag = "kind", rename_all = "camelCase")] pub enum DiffTarget { WorkTree { dir: PathBuf }, Branch { root: PathBuf, branch: String } }`
  - `pub fn default_branch(root: &Path) -> Option<String>`
  - `pub fn base(target: &DiffTarget) -> Result<String, String>`: WorkTree → `merge-base(default, HEAD)`, or `HEAD` if no default branch, or empty tree `4b825dc642cb6eb9a060e54bf8d69288fbee4904` if no commits; Branch → `merge-base(default, branch)`.
  - `pub struct FileChange { path: String, old_path: Option<String>, status: Status /* Added|Modified|Deleted|Renamed */, additions: u32, deletions: u32, binary: bool }`
  - `pub fn summary(target: &DiffTarget) -> Result<Vec<FileChange>, String>`: WorkTree → `git diff -z --numstat --find-renames <base>` + `--name-status` for status, plus `git ls-files -z --others --exclude-standard` as Added (binary if a NUL appears in the first 8 KB); Branch → same against `<base> <branch>`, no untracked. Sorted by path.
  - `pub struct Patch { text: String, truncated: bool }`; `pub fn patch(target: &DiffTarget, path: &str) -> Result<Patch, String>`: tracked → `git diff --find-renames <base> [<branch>] -- <path>`; untracked → `git diff --no-index -- /dev/null <path>` (exit code 1 is success). Over 1 MB → `text` empty, `truncated: true`.
  - Commands `diff_summary(target)`, `diff_patch(target, path)`.
